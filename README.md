# PayLonSon 作品集

我做的網頁遊戲和小工具，全部免安裝、手機就能用。

👉 https://paylonson.github.io/ProjectHomePage/

| 分類 | 作品 | 說明 |
|---|---|---|
| 遊戲 | [三扇門｜惡夢 DoorVault](https://paylonson.github.io/DoorVault/) | 5–10 分鐘的網頁恐怖遊戲，連過三扇成語門才能醒來 |
| 遊戲 | [大富翁](https://paylonson.github.io/Monopoly/) | 面對面用手機房號連線的台灣版大富翁，2–6 人，含政策卡與台灣歷史事件 |
| 遊戲 | [火柴人地城 StickDungeon](https://github.com/PayLonSon/stickdungeon)（開發中） | 火柴人風格、擲骰回合制的 2–4 人合作地城冒險 |
| 小工具 | [分帳房 SplitRoom](https://paylonson.github.io/SplitRoom/) | 多人同步記帳，自動算出誰該給誰多少 |
